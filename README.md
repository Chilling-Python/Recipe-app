# Recipe App

A web application built with Lovable and claude.

## 🚀 How to Run Locally

### Option 1 — Python (Recommended, no install needed)

1. Clone the repository:
   ```bash
   git clone https://github.com/Chilling-Python/Recipe-app.git
   cd Recipe-app
   ```

2. Start a local server:
   ```bash
   python -m http.server 8000
   ```

3. Open your browser and go to:
   ```
   http://localhost:8000
   ```

---

### Option 2 — Node.js

1. Clone the repository:
   ```bash
   git clone https://github.com/Chilling-Python/Recipe-app.git
   cd Recipe-app
   ```

2. Run:
   ```bash
   npx serve .
   ```

3. Open the URL shown in the terminal (usually `http://localhost:3000`)

---

### Option 3 — VS Code Live Server

1. Install the **Live Server** extension in VS Code
2. Open the project folder in VS Code
3. Right-click `index.html` → **"Open with Live Server"**
4. The app will open automatically in your browser
